# Task 0：Agent 基础与环境准备

## 学习心得

刚开始学 Agent 时，我容易把它想成“接上大模型、能回答问题的程序”。看完 Chapter 1，再自己跑了一遍示例后，我觉得关键差别在于它不只是回答一句话，而是会根据任务继续决定下一步：需要信息时调用工具，拿到结果后再判断，然后决定继续还是结束。ReAct 里的“思考、行动、观察”把这个过程串起来；Harness 则负责检查模型提出的工具调用，并把结果放回过程记录里。

这次我先把官方仓库的环境配好，再运行了 web-search-agent 的 offline-demo。看到轨迹里有模型决策、工具调用和工具返回，整个流程一下子比只看概念清楚了。不过我也记住了一个容易混淆的地方：这次跑的是离线示例，里面的轨迹和搜索结果是演示数据，不等于真正请求了 LLM，也不等于实时搜索。所以我现在会把“程序跑通”和“真实模型、真实工具已经接通”分开看。对我来说，Agent 不是模型单独完成所有事，而是模型、上下文、工具和负责执行流程的程序一起配合；工具结果能不能正确进入下一轮，也会影响最后的回答。

## 实验记录

- 环境：官方仓库 .venv，Python 3.13.13
- 实验：Chapter 1 web-search-agent 的 offline-demo
- 结果：输出示例 ReAct 轨迹，并生成 demo.json
- 说明：这是离线演示，不是实时搜索，也没有调用真实 LLM API
